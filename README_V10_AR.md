# فرتكه V10

هذه النسخة مبنية على V9 وتحتوي على:
- صفحة استعادة كلمة المرور متوافقة مع تدفق Supabase PKCE/الرابط المباشر.
- رسالة خطأ واضحة عند توقف إرسال رسائل الاستعادة بسبب حدود Supabase.
- تثبيت رابط الاستعادة على GitHub Pages الصحيح.
- تحديث إجباري للكاش الخاص باللوجو على الكمبيوتر والموبايل.

مهم: إرسال البريد نفسه يتم بواسطة Supabase، وليس GitHub Pages. مزود البريد الافتراضي في Supabase يفرض حدودًا على رسائل Auth؛ إذا ظهر حد إرسال، يلزم الانتظار أو إعداد SMTP مخصص.
