# فرتكه V7

نسخة تجمع وظائف V6 مع إصلاح استعادة كلمة المرور وتخصيص اللوجو وصور الأقسام والواجهة.

## بعد الرفع
1. تأكد أن Site URL هو: https://mohmdfartka00-collab.github.io/fartkaa/
2. أضف Redirect URL: https://mohmdfartka00-collab.github.io/fartkaa/reset.html
3. شغّل `supabase_setup_v7.sql` مرة واحدة في SQL Editor.
4. سجل الدخول بحساب المدير.
5. من لوحة الإدارة استخدم إضافة منتج أفليت لاسم المنتج + رابط الأفليت + الوصف + السعر + رفع الصورة.
6. من تخصيص المتجر تقدر ترفع اللوجو وصورة الواجهة وصور الأقسام والنص السفلي.

لا تضع أي مفتاح سري للدفع داخل ملفات الموقع.
