# فرتكه V5 — النسخة الجديدة المتكاملة

هذه النسخة تجمع الإصلاحات والتطويرات المطلوبة في مشروع واحد.

## أهم ما تم إصلاحه
- تسجيل الدخول والاشتراك بالبريد وكلمة المرور مع جلسة محفوظة.
- إنشاء `profiles` تلقائيًا عند إنشاء حساب في Supabase Auth.
- قائمة ☰ على الموبايل والكمبيوتر: الدخول/الاشتراك، الطلبات، المفضلة، التتبع، الإعدادات، المنتجات ولوحة الإدارة.
- لوحة أفليت واضحة: رابط أفليت + اسم المنتج + وصف + سعر + سعر قديم + متجر + قسم + صورة.
- رفع صورة المنتج من الهاتف/الكمبيوتر إلى Supabase Storage.
- معاينة الصورة قبل الحفظ.
- رابط شراء الأفليت يفتح في نافذة جديدة مع `nofollow sponsored`.
- إصلاح نافذة اليافطة/النوافذ المنبثقة وزر × وEscape والخلفية.
- تصميم جديد مستوحى من تجربة المتاجر الكبيرة بدون نسخ هوية Amazon أو noon.

## أهم خطوة قبل الاختبار
في Supabase افتح SQL Editor وشغّل:

`supabase_setup_v5.sql`

الملف ينشئ/يصلح:
- سياسات المنتجات.
- Storage bucket باسم `product-images`.
- سياسات رفع الصور للمدير.
- سياسة قراءة الصور للعامة.
- Trigger لإنشاء profile تلقائيًا بعد التسجيل.
- سياسات حساب العميل.
- إعدادات الواجهة.
- جدول ضغطات الأفليت.

## جعل حسابك مديرًا
بعد إنشاء الحساب من الموقع شغّل:

```sql
update public.profiles
set role='admin'
where id=(select id from auth.users where email='YOUR_EMAIL@example.com');
```

ثم سجّل خروجًا ودخولًا من الموقع.

## تأكيد البريد
في مشاريع Supabase المستضافة، تأكيد البريد يكون مفعّلًا افتراضيًا في إعدادات Email Auth. لذلك بعد الاشتراك قد تحتاج إلى فتح رسالة التأكيد ثم تسجيل الدخول. لو رسائل البريد لا تصل، راجع Auth Logs/SMTP؛ مزود البريد الافتراضي له حدود إرسال منخفضة، وللاستخدام الفعلي يفضل SMTP مخصص.

## الصور
من لوحة الإدارة:
1. إضافة منتج أفليت.
2. ضع رابط الأفليت.
3. ارفع الصورة.
4. اكتب الوصف والسعر.
5. اضغط إضافة المنتج.

الصورة تذهب إلى Storage، ورابطها يحفظ داخل `products.image_url`.

## الدفع
الدفع الحقيقي يحتاج نشر Edge Functions ووضع مفاتيح Paymob السرية داخل Secrets. لا تضع Secret Key في ملفات الموقع.
