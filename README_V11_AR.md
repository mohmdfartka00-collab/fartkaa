# فرتكه V11 — النسخة الشاملة

## ما تم إصلاحه
- إصلاح مهم في الحسابات: تسجيل الدخول لم يعد يعيد حساب المدير إلى `customer`.
- إنشاء `profiles` تلقائيًا عند إنشاء حساب جديد، مع إصلاح الحسابات القديمة التي ليس لها profile.
- إضافة رابط تأكيد البريد عند التسجيل باستخدام عنوان الموقع الحقيقي.
- تحسين صفحة استعادة كلمة المرور لموقع GitHub Pages الثابت، مع عدم إجبار PKCE في المتصفح.
- لوحة إدارة كاملة للمدير: إضافة/تعديل/حذف منتجات الأفليت.
- حقول المنتج: الاسم، المتجر، رابط الأفليت، صورة، السعر، السعر القديم، القسم، المخزون، الوصف.
- رفع الصور إلى Supabase Storage.
- تغيير اللوجو وصورة الواجهة وصور الأقسام والنص السفلي.
- صلاحيات قاعدة البيانات للمنتجات والصور والإعدادات.

## مهم جدًا: جعل حسابك مديرًا
بعد رفع النسخة وتشغيل الحساب مرة واحدة، افتح Supabase > SQL Editor.

افتح `supabase_setup_v11.sql`، وفي آخر الملف ستجد السطر:

`update public.profiles set role='admin' where id=(select id from auth.users where lower(email)=lower('YOUR_EMAIL@example.com'));`

استبدل `YOUR_EMAIL@example.com` بإيميل حسابك ثم شغّل السطر.

بعدها اعمل تسجيل خروج من الموقع ثم دخول مرة أخرى. ستظهر لك لوحة الإدارة.
