# متجر فرتكه — نسخة احترافية أولية

## الموجود
- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر.
- هوية فرتكه بنفسجي/ذهبي ولوجو SVG.
- أقسام وبحث وفرز.
- منتجات ومصادر وروابط شراء.
- سلة مشتريات محفوظة في المتصفح.
- قسم عروض ونشرة بريدية.
- إعدادات SEO أساسية وrobots/sitemap.
- نموذج "الصق رابط المنتج".

## مهم قبل النشر
هذه نسخة واجهة Front-end جاهزة للتجربة. جلب **اسم المنتج + صورته + السعر تلقائياً من رابط نون/طلبات/أمازون** يحتاج API/تكامل رسمي أو خدمة مسموح بها؛ لا ينبغي كشط المواقع أو تجاوز الحماية.

لتحويلها لمتجر تجاري حقيقي نحتاج:
1. استضافة + دومين.
2. لوحة تحكم وقاعدة بيانات.
3. تكامل روابط الأفلييت لكل متجر.
4. خدمة/واجهات API للاستيراد المصرح.
5. وسيلة دفع/واتساب/شحن حسب طريقة البيع.
6. Google Search Console وAnalytics بعد تحديد الدومين.


## إضافة منتج أمازون كأفليت
1. من حساب شركاء أمازون استخدم SiteStripe لإنشاء رابط الشراكة للمنتج.
2. ضع رابط الأفليت في خانة "رابط الأفليت / رابط الشراء".
3. اكتب اسم المنتج والسعر.
4. ضع رابط صورة المنتج إذا كان لديك مصدر صورة مسموح به.
5. اضغط "إضافة المنتج إلى فرتكه".
6. زر "شراء الآن" في بطاقة المنتج يفتح رابط الأفليت، وبالتالي تظل إحالة الشراء مرتبطة برابط الشراكة.

ملاحظة: Amazon توضح أن SiteStripe يمكنه إنشاء روابط مباشرة لصفحات المنتجات وإدراج معرف الشراكة والتتبع، كما توفر Product Advertising API للوصول البرمجي إلى بيانات المنتجات عند توفر الأهلية.
