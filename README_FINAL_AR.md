# فرتكه — النسخة النهائية المجمعة

هذه النسخة تجمع تطويرات المتجر، حسابات العملاء، Supabase، رفع الصور، إدارة المنتجات، روابط الأفليت، الطلبات، الدفع المجهز، تتبع الشحنات، ولوحة الإدارة، مع إصلاح نافذة اليافطة وزر الإغلاق.

## روابط الأفليت
من لوحة الإدارة > إضافة منتج، ضع رابط الأفليت في خانة «رابط الأفليت». سيظهر للعميل زر «شراء من المتجر الأصلي ↗» ويفتح الرابط في تبويب جديد مع خصائص nofollow/sponsored.

## الصور
يمكن رفع صورة المنتج من الجهاز مباشرة إلى Storage bucket باسم `product-images` بشرط تطبيق سياسات Storage الموجودة في إعدادات المشروع.

## Supabase
راجع ملفات `supabase_migration_v2.sql` و`ربط_سوبابيز_والدفع_والصور.md` قبل النشر النهائي.

## الدفع
الدفع الحقيقي يحتاج مفاتيح بوابة الدفع السرية داخل Supabase Edge Functions Secrets، وليس داخل ملفات الموقع.
