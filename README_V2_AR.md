# فرتكه V2 — متجر إلكتروني + حسابات + طلبات + تتبع

## ما تم تطويره
- حسابات العملاء عبر Supabase Auth.
- بيانات العميل والعنوان ورقم الهاتف.
- سلة بكميات وتحديثات.
- مفضلة.
- صفحة تفاصيل المنتج وتقييمات جاهزة للربط.
- كوبونات خصم.
- إنشاء طلب حقيقي في قاعدة البيانات.
- خصم المخزون عند إنشاء الطلب.
- رقم طلب ورقم تتبع تلقائيان.
- خط زمني لتتبع الشحنة.
- لوحة مدير لإدارة المنتجات والطلبات وحالة الشحنة.
- حقول رقم التتبع وحالة الطلب.
- إعداد دفع بالبطاقة عبر بوابة خارجية بدون تخزين بيانات البطاقة.
- إصلاح نافذة البحث على الكمبيوتر: لا تظهر تلقائيًا ويمكن إغلاقها بـ × أو Esc.
- تصميم متجاوب للموبايل والكمبيوتر.

## مهم جدًا قبل تشغيل الطلبات
1. افتح Supabase > SQL Editor.
2. شغّل `supabase_migration_v2.sql` كاملًا.
3. أنشئ حساب المدير من الموقع.
4. نفّذ آخر سطر الخاص بجعل الحساب `admin` بعد وضع بريدك.
5. تأكد أن Bucket الصور `product-images` موجود وسياسات الإدارة من النسخة السابقة ما زالت موجودة.

## الدفع بالفيزا
الواجهة مجهزة، لكن الدفع الحقيقي لا يمكن تفعيله بدون حساب تاجر ومفاتيح سرية من بوابة دفع. هذه المفاتيح **لا توضع داخل `index.html` أو `script.js`**.

القالب موجود في:
`supabase/functions/create-payment/index.ts`

بعد اختيار مزود الدفع، توضع المفاتيح في Supabase Secrets ويتم نشر Edge Function، ثم يوضع رابط الدالة في `payment-config.js` ويصبح `enabled:true`.

## التتبع
العميل يستخدم رقم الطلب أو رقم التتبع. المدير يغيّر الحالة من لوحة الإدارة، وكل تحديث يُسجل في `shipping_events` ويظهر في الخط الزمني.

## التشغيل
المشروع موقع ثابت ويمكن رفعه على أي استضافة تدعم HTML/CSS/JS. لا تحتاج Node لتشغيل الواجهة نفسها.
